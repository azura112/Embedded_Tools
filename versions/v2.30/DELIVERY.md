3. CHANGELOG 当版条目 = **+1**（`[2.30.0]` 进入条目循环）；
4. 覆盖率行 = **+1**（本档进场，逐档 1 槽）；
5. 占位符拦截面 = **−1**（v2.29 有主档 + r2 两份 = 2 槽；本版仅本档 = 1 槽）。
