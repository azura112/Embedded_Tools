# REQ 条目模板（BACKLOG.md 需求池条目骨架）

> 复制到 `BACKLOG.md`「需求池」区使用；五字段齐备才算 REQ（DoD：拒绝必有原因，接受必有优先级）。
> 状态机：`速记 → 提议中 → 已接受 / 已拒绝 / 暂缓 → 已纳入 vX.Y → 已完成（REVIEW 通过）→ 关闭`。
> 来源用词统一：`用户直连 / 使用反馈 / 功能想法 / 迁移自 XX / 执行者建议`。

```markdown
### REQ-n <标题>
- 状态：提议中 | 已接受 | 已拒绝 | 暂缓 | 已纳入 vX.Y | 已完成 | 关闭
- 优先级建议：P0 | P1 | P2 | P3
- 问题/动机：<现在哪里不舒服，一句话>
- 期望行为：<可核验的期望结果>
- 来源：<用户直连 / 使用反馈 / 功能想法 / 迁移自 FT-n / 执行者建议，含日期>
```

评估拍板 = Owner（Agent 可建议，不拍板）。「暂缓」连续 3 次判定未纳入 → 强制升级为纳入或拒绝。
