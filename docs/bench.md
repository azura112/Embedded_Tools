# host 基准 (docs/bench)

> 度量工具:`tools/bench.c`(固定迭代 + 5 轮取中位数 + 预热 1 轮 + 基线操作配对先测,防 DCE volatile 汇聚;v2.25 起带相对比值列)。
> **声明:绝对值不具跨机器可比性**(仅同机版本间回归对比与量级判断);**比值列(基线操作 = 1.0)在同构构建间可比**(v2.25 P2-2,口径声明③ 落地);
> 复测请附完整环境注记,无注记数字不入本文档。
>
> **口径声明(v2.6 P3-1 / `CO-14(v2.5)`,务必先读)**: 本表数字**仅供量级参考,
> 不作回归判据**。v2.5 评审期实测: 同机同日复跑与文档值差幅最大 **59%**
> (主站组帧 40.0 vs 60.0 ns/op; 一轮事务 110.0 vs 175.0), 原因是基线无负载控制
> (无 CPU 亲和/无预热/`clock()` 粒度 ~1ms)。**据此**:
> ① 表中数字不得用于判定"某版性能是否回归"(量级一致即可);
> ② 任何性能结论须附同轮复跑的原始读数与机器负载状态;
> ③ 相对比值(基线操作 = 1.0)+ 预热 + 固定迭代 **已实施(v2.25, `CO-6(v2.8)` 升格/M1-①)**——自 v2.25 起结果表**双列呈现**(绝对值 + 比值), 需要判别力时以比值列为准(同构构建间可比), 历史表(v1.7.0 基线)原样保留不覆写。基线操作 = 库外标量 LCG 混合链(40e6 iters/轮, 配对先测, 基线行恒 1.0); 单轮测量窗校准 ≥50ms(`clock()` ~1ms 粒度下量化误差 ≤2%)。**稳定性判据(v2.26 P0-3 稳健化, `CO-3(v2.25)` 机制裁决——推荐组合 (i)+(ii))**: 取 **≥3 对**(每对 = 同机同构建连续两轮)逐行比值之比, 以**逐行中位**为判据值, 判据 = 中位 ∈ **[0.7, 1.4]**; **环境限定 = 普通桌面负载态**(无 CPU 亲和/无负载静默, 本仓开发机实测环境)——判据仅在该环境声明成立, 受控静默环境下应更紧。依据: v2.25 评审 4 对 92 行对实测单对极值 0.62–1.55(桌面负载态), 单对单轮协议不稳健; 中位化后极值收敛, 带宽按评审实测 excursion 放宽一档。(v2.25 原判据 = 连续两轮 ∈ [0.8,1.25], 评审实测 7/92 行对超界判 FAIL——被本条取代。)

## 观察与备注

- ringbuf POW2 与非 POW2 块吞吐无差异:该访问模式下内部操作相同(无取模,自动递增索引);
- crc16-ccitt 位算法与查表在本模式(4KB 驻 L1 缓冲)下同达吞吐上限,查表的价值预期在缓存敏感/更大缓冲场景;
- crc32 位算法 125 MB/s(≈ ccitt 位算法的 1/4,反射+32 位宽所致);v1.9 补表路径后 500 MB/s,与 ccitt 表同档;
- xmodem 有效吞吐含帧头/补码/CRC 计算(133B 线路字节承载 128B 载荷,协议开销 3.9%);
- kv 速率受 host 虚拟 flash(memcpy 模拟)影响,**不代表真实 flash 时序**(真实页擦 ms 级);
- `pid step` 含 P/I/D 三项 + 饱和 int64 乘除, 15 ns/op 量级(定点闭环 10kHz 采样下 < 0.02% CPU);
- `stats push` Welford 单样本更新 6 ns/op, 与 filter movavg(2 ns/op)同档, 适合在线长期统计;
- `medfilt push` 小窗插入排序 O(win²): win=5 为 11 ns/op, 量级与 smap 查找同档; win 增到 15 时按平方律增长, 高频采样场景窗口别贪大;
- `sched poll_once` 含时基读取×3 + 任务调用 + 耗时计量, 5 ns/op 量级 —— 任务耗时统计的诊断收益远大于计量开销;
- `hist push` O(1) 等宽映射 2 ns/op(与 movavg 同档); `percentile` 逐桶线性扫 10 ns/op(16 桶), 255 桶按桶数线性增长 —— 高频调用场景桶数别超配;
- `modbus` 帧处理(8B 请求 → CRC 校验 + 应答构造 13B)≈160 ns/帧; 真机瓶颈在串口线速(115200 下 8B≈0.7ms), 协议处理可忽略;
- `modbus_master` 请求组帧(含 CRC)≈60 ns/op, 一轮完整事务(组帧 → 上线 → 应答 CRC 校验+解析 → 终态)≈175 ns/op ——
  仍远低于串口线速(115200 下 8B 请求+13B 应答 ≈1.8ms), 主站协议开销可忽略;
- **v2.5 本机抖动说明(如实记录)**: 本轮复测机处于负载波动状态, 各行在 3 次连跑间整体同向漂移
  (modbus 行 32/36/44 ms 中位数 ↔ 115~220 ns/帧; 主站组帧 50~85 ns/op; 一轮事务 155~210 ns/op)。
  `et_modbus.c` 本版**未改动**, 其读数变化属 `clock()` ~1ms 粒度 + 本机负载抖动, **非回归**;
  表内取 3 次连跑的中位代表值。
- crc16-modbus 位算法 142.9 MB/s → 查表 500.0 MB/s(v2.2 P5-3 补表后与 ccitt 同档, 反射位算法为 ccitt 的 ~1/3.5);
- 复现:`make bench`(或 Makefile 注释中的 gcc 命令),查表变体 `make bench-table`。
